# 项目架构

## 运行结构

项目采用纯静态架构，无后端与数据库依赖。

1. `index.html` 定义首页、答题、仪式和结果四个界面。
2. `app-v2.js` 保存题目、职业资料、计分规则及界面状态切换。
3. `styles.css` 提供做旧信纸、西幻花饰和响应式布局。
4. `overrides.css` 负责职业画像、长文结果与打印输出的细节。
5. `assets/cards` 保存 16 张职业塔罗牌。
6. `dist` 是与源文件同步的可部署成品。

## 计分模型

28 道题严格交替测量两组倾向：

- 奇数题：勇气、求知、创造、洞察。
- 偶数题：共情、自然、联结、独立。

每次选择为对应倾向增加 1 分。完成后分别在两组中取最高分，并使用 `${核心驱动力}|${关系倾向}` 查找职业。相同分数目前按倾向数组的稳定顺序决定，保证同样答案始终得到同样结果。

## 数据完整性

`scripts/validate-project.cjs` 在不启动浏览器的情况下加载应用数据，检查题目、维度、职业映射、文本长度、画像和发布目录。GitHub Actions 会在每次推送和 Pull Request 时执行同一套规则。

## 隐私

所有答题和计算都在用户浏览器中完成；项目不上传、不保存用户答案，也不包含第三方统计脚本。
