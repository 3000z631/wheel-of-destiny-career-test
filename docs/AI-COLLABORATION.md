# AI 协作记录

本项目采用 Vibe Coding 工作流，由项目所有者定义产品方向、审美、题目标准和职业文案，并使用 AI 协助完成视觉探索、前端实现、结构化重构与自动质检。

## 人工负责

- 确定西幻、塔罗、做旧信纸的视觉方向。
- 选择并反复校准职业画像风格。
- 提供 16 种职业的正式解析文案。
- 发现题目选项不并列、结果内容过短等产品问题。
- 决定发布范围与商业化方向。

## AI 协助

- 将产品要求转化为静态网页结构和交互。
- 实现 28 道题的状态管理、计分与职业映射。
- 根据人工反馈重构题目，使选项保持同一情境和行动层级。
- 接入完整解析、移动端排版与塔罗牌翻转效果。
- 编写自动质检脚本、工程文档和 GitHub 工作流。

## 验证方式

- 通过自动脚本验证题量、维度、职业组合、长文和画像完整性。
- 使用真实浏览器完成 28 道题，验证“勇气 + 自然”得到“驭兽师”。
- 在手机宽度下检查结果卡、完整长文和操作按钮。

AI 输出不被视为天然正确；关键内容、审美方向和最终验收均由项目所有者决定。
