# GitHub 发布检查清单

## 仓库初始化

- [ ] 选择合适的仓库可见性。
- [ ] 设置仓库简介与项目主页。
- [ ] 确认默认分支为 `main`。
- [ ] 确认 GitHub Actions 的 Quality Check 通过。

## Milestone 与任务

- [ ] 创建 `v1.0 · 性格测试 MVP` Milestone。
- [ ] 根据 README 中的六项任务建立 Issues。
- [ ] 为每个 Issue 写清任务范围和验收标准。
- [ ] 把 Issues 关联到 Milestone，并在完成后关闭。

## 固定快照

- [ ] 确认仓库工作区干净。
- [ ] 再次运行 `npm test`。
- [ ] 创建带说明的 `v1.0.0` 标签。
- [ ] 创建 GitHub Release，并附上功能概览和验收结果。
- [ ] 如需公开演示，再单独启用 GitHub Pages。
