# 路线图与 Milestone 计划

## v1.0 · 性格测试 MVP

目标：形成一个内容完整、移动端可运行、具备自动质检和固定发布快照的版本。

- [x] 完成 28 道情境题

- [x] 接入 16 种职业组合
- [x] 接入完整职业解析

- [x] 建立自动质量检查
- [ ] 建立 GitHub Issues 与 Milestone

## v1.1 · 体验优化

- 增加答题进度的临时保存与恢复。
- 优化分数相同时的二次判定。
- 增加结果海报导出，不依赖浏览器打印。
- 增加题目可读性与结果分布的匿名测试记录。

## v2.0 · 商品化准备

- 增加订单或兑换码接入方案。
- 增加访问授权与防止链接直接传播的机制。
- 补齐用户协议、隐私说明和内容免责声明。
